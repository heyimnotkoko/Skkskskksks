# KroMusic

Lightweight Telegram music bot for Railway. The complete application code is contained in `main.py`.

## Required variables
`BOT_TOKEN`, `OWNER_ID`, `API_ID`, `API_HASH`

`SESSION` is optional. The owner can use `/المساعد` to add the assistant account through phone, login code (dots/spaces accepted), and 2FA password when enabled.

Developer: @krofullpower
Channel: @dlxfullpower

Run locally/Railway: `python main.py`
